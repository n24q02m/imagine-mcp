## 2025-02-14 - Prevent Environment Variable Injection in Relay Configuration
**Vulnerability:** The `apply_config` function in `src/imagine_mcp/relay_setup.py` accepted configuration dictionaries from untrusted sources (such as a remote relay or an OAuth form) and blindly loaded their key-value pairs directly into `os.environ`. This allowed an attacker to inject arbitrary and potentially dangerous environment variables like `PYTHONPATH`, `LD_PRELOAD`, or others to achieve Remote Code Execution or privilege escalation.
**Learning:** The function iterated over the user-provided config dictionary and trusted all provided keys because it assumed only credential keys would be sent.
**Prevention:** Always validate configuration payloads parsed from untrusted sources against a strict allowlist (like `CREDENTIAL_KEYS`) before applying them to critical system states such as `os.environ`.
