## 2025-02-28 - Consolidate status check to avoid redundant disk reads
**Learning:** In the `config` tool's `status` handler, evaluating `_creds_state()` and `_providers_configured_live()` in separate concurrent `asyncio.to_thread` dispatches results in redundant disk reads of the `PerPluginStore`. Although both are fast, aggregating them into a single synchronous helper avoids unnecessary I/O overhead and thread context-switching.
**Action:** When a single logical operation requires reading the same disk-backed state multiple times, consolidate those reads into a single synchronous function and dispatch it once via `asyncio.to_thread` or use a caching mechanism if appropriate.
